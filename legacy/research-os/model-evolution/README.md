# Model Evolution History｜模型进化史

Historical record of how the Investment Research OS model changes over time.

记录投资研究操作系统模型随时间如何演变。

## Purpose｜目的

Understand not only **what** the model contains, but **why** each variable exists.

不仅了解模型**包含什么**，更要了解每个变量**为何存在**。

## Record for each variable｜每个变量应记录

- When was it first discovered?｜何时首次发现？
- Why was it considered?｜为何被考虑？
- What evidence existed?｜当时有何证据？
- What event tested it?｜哪个事件检验了它？
- Was it strengthened or weakened?｜被强化还是弱化？
- When was it promoted into the core model?｜何时晋级为核心模型？
- Was it later downgraded or rejected?｜后来是否降级或否决？

## Link to Observation Zone｜与观察区的关系

Candidates move: Observation Zone → (Validated) → Core Model, or → Rejected / Dormant. Each transition should leave a dated entry here.

候选路径：观察区 →（已验证）→ 核心模型，或 → 否决/休眠。每次状态变更应在此留下带日期记录。

## Objective｜目标

Support continual learning: `Model(t+1)` better than `Model(t)` via evidence, calibration, and honest error recognition.

支撑持续学习：通过证据、校准与诚实的误差识别，使 `Model(t+1)` 优于 `Model(t)`。
