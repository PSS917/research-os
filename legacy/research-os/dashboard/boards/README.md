# Research OS Daily Board｜投资研究OS日报看板

This folder holds **Research OS Daily Board** HTML templates — scannable, bilingual (EN + 简体中文) one-screen dashboards for the Investment Research OS.

## What this is

- A **structured research board**: expectation gaps, claim labels (CONFIRMED / RELIABLE / HYPOTHESIS / TENTATIVE), Thinking Tutorial strip, watchlist highlights, Event Book pointers.
- Designed for post-event digestion and archive-verified figures only.
- Dark institutional layout (≈1920×1080 friendly, also scrollable).

## What this is not

- **Not a tip sheet** — no buy/sell recommendations, no personalized trading advice.
- Not a live data feed; boards are static snapshots from verified archive prints.

## Naming

`YYYY-MM-DD-<event-slug>-board.html`

Example: `2026-09-16-post-fomc-board.html`

## Event Book

Related event packets live under `research-os/events/` (e.g. `events/fomc-2026-09/`).

## Tone

Research / education. Abbreviate with bilingual gloss where useful, e.g. **FOMC** (Federal Open Market Committee｜联邦公开市场委员会).
