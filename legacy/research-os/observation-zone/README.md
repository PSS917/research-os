# Observation Zone｜观察区

Formal holding area for candidate research variables that are **not** yet part of the core Investment Research OS model.

正式存放尚未纳入核心投资研究模型的候选变量。

## Purpose｜目的

When a potentially important missing variable is identified, do **not** insert it into the core model immediately. Isolate it here first, run independent analysis, and decide based on evidence.

发现潜在重要缺失变量时，**不要**立刻写入核心模型。先在此隔离、独立分析，再依证据决策。

## Required fields per candidate｜每条候选需记录

- Variable / Hypothesis｜变量 / 假设
- Why it might matter｜为何可能重要
- Transmission mechanism｜传导机制
- Evidence supporting it｜支持证据
- Evidence against it｜反对证据
- Missing evidence｜缺失证据
- Required data｜所需数据
- Next validation event｜下次验证事件
- Confidence level｜置信度
- Current status｜当前状态

## Statuses｜状态

| Status｜状态 | Meaning｜含义 |
|---|---|
| **Candidate｜候选变量** | Interesting but insufficient evidence.｜有意思但证据不足。 |
| **Observation｜观察变量** | Reasonable mechanism; needs more validation.｜机制合理；需更多验证。 |
| **Validated｜已验证变量** | Repeated evidence supports promotion into the core model.｜反复证据支持纳入核心模型。 |
| **Rejected / Dormant｜否决/休眠变量** | Evidence does not support it, or currently irrelevant.｜证据不支持，或当前不相关。 |

## Rules｜规则

- Do not forget observation variables; revisit them automatically during similar future events.
- 不要遗忘观察变量；在类似未来事件中自动回访。
- Promotion / rejection decisions should be logged in Model Evolution History.
- 晋级 / 否决决策应记入模型进化史。
