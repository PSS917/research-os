## 2. 生命周期模板 Lifecycle templates (每个重大事件必须走完)
### A. 发布前 Pre-release (T-2d→T-1h)
1. 共识与区间 Consensus & range (来源+时间) 2. 我们的预测 vs 共识 (预期差) 3. 情景树 Hot/Inline/Cool 及概率 4. 每个情景的跨资产传导 (2Y/10Y/USD/JPY/NDX/SOX/个股) 5. 受影响个股清单与敏感度 6. 观察清单: 看哪些分项 7. 证伪条件 8. 初学者解读
### B. 发布时 Live (T→T+2h)
1. 实际值 vs 共识 vs 我们 (Surprise = Actual − Expected) 2. 分项拆解 3. 首30分钟市场反应 (Headline vs Fundamental) 4. 反应分解 ΔPrice ≈ ΔEPS + ΔMultiple(rates) + ΔPositioning + ΔLiquidity 5. 是否触发模型更新
### C. 发布后复盘 Post-release (T+1d)
1. 原假设→预测→实际→偏差→反应 2. 误差分类 (Fundamental / Expectation-pricing / Market-reaction / Timing / Probability) 3. 根因 4. 模型重校准 (哪些假设改变、改多少) 5. 估值更新 (重跑Excel) 6. 学习要点 7. 追加到当日 Daily OS 更新
### E. 思考过程标准 (Teaching v2.1, master prompt Part C)
若事件由重大新闻驱动（自选股/指数单日≥3%或市场热议），必须附「新闻解读图」(news.html，模板 pipeline/infographic)。每本事件书必须展示推理过程：七步思考法 — 先问对问题：谁在乎、为什么在乎 → 市场已经定价了什么 → 搭因果链，每环配一个检验数据 → 找每一环的断点 → 用工具箱逐一质疑 → 给对立观点最强版本，再用证据裁判 → 写下「如果我错了，会先看到什么」；质疑工具箱逐一应用（第一性原理、二阶思维、反向思考、市场已经定价了什么、谁在对手盘、基础概率、假设清单与证伪），每个工具含真实数字与「轮到你」；对立观点最强版本+证据打分；推理测验（为什么/如果…会怎样）；发布后逐环因果链复盘：
