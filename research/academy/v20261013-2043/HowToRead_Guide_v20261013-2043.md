## 1. 报告类型：什么时候读、读什么
| 报告 | 多久一次 | 回答什么问题 | 新手先看 |
|---|---|---|---|
| 仪表盘 Dashboard | 随时 | 今天市场整体冷还是热？ | 顶部指标卡、27家热力图 |
| 每日总览 Daily | 每天 | 昨晚发生了什么、接下来7天看什么 | 30秒看懂 |
| 宏观专题 Macro | 每周/每月 | 利率、通胀、美元/日元如何影响股票 | 利率图、通胀图 |
| 台日韩雷达 Radar | 每天/每周 | 亚洲哪些产业题材在变强/变弱 | 题材排名表 |
| 事件书 Event book（发布前/时/后） | 每次重要数据或财报 | 市场在猜什么、我们怎么想、公布后对答案 | 判断表（几个阈值） |
| 个股深度 Company | 每月 + 每次财报 | 公司值多少钱、股价隐含了什么 | 估值区间图、三情景 |
| Excel 模型 | 同个股 | 所有数字怎么算出来（可自己改假设） | Scenarios 工作表 |
| 我的报告 My Reports | 自动 | 所有交付过的报告和历史版本 | 搜索框 |

**财务经理视角：**日报像「每日现金日报」，宏观像「经营环境分析」，事件书像「月结前的预算 vs 实际预测」，个股报告像「投资项目可研报告」，Excel 就是「底稿」。

## 2. 每种图怎么看
| 图 | 坐标/颜色 | 只记住一件事 |
|---|---|---|
| 股价 vs 三情景价值 | 蓝线=股价；红/蓝/绿虚线=悲观/基准/乐观估值 | 股价在哪条线附近，说明市场接近哪种剧本 |
| 季度财务 | 深蓝柱=收入，橙柱=自由现金流，红线=营业利润率 | 现金流是否跟着收入一起长 |
| 三情景柱状图 | 三根柱=三种估值，黑线=现价，紫线=概率加权 | 现价落在哪两根柱之间 |
| 2/4/6/8季度检验 | 横轴=未来几个季度，线=折回今天的价值 | 若连乐观线都低于现价，说明价格要求更远的未来 |
| 研究逻辑图 | 7个方框从左到右 | 每个结论都要有证据和反证 |
| 宏观利率图 | 各条利率线 | 2年期看美联储，10年期看长期折现 |
| 雷达柱状图 | 1周/1月/3月平均涨跌 | 短期强、长期弱=新启动；长期强、短期弱=可能降温 |
| 事件教学图（带注释） | 绿区/红区=阈值 | 公布值落在哪个区 |

## 3. 估值方法白话版（带一个完整例题）
### 3.1 <abbr title="现金流折现：把未来每年的自由现金流折回今天加总｜Discounted Cash Flow｜比喻：像评估一个项目的净现值（NPV）">DCF</abbr>（Discounted Cash Flow：现金流折现：把未来每年的自由现金流折回今天加总）
**比喻：**买股票像买一个每年产生现金的项目，DCF 就是算这个项目的 NPV。
**例题（纯举例，非任何真实公司）**——符号：
- **F₁** = 第1年<abbr title="经营现金流减资本开支，真正能分给股东的钱｜Free Cash Flow, FCF｜比喻：像现金流量表里「经营现金流 − 购置固定资产」">自由现金流</abbr>（Free Cash Flow, FCF：经营现金流减资本开支，真正能分给股东的钱） = 100（百万美元）
- **g** = 前5年每年增长 = 10%
- **r** = <abbr title="把未来的钱换算成今天的钱时用的利率｜discount rate / WACC｜比喻：像你评估投资项目时的门槛回报率（hurdle rate）">折现率</abbr>（discount rate / WACC：把未来的钱换算成今天的钱时用的利率）（WACC） = 10%
- **g∞** = 第5年以后的永续增长 = 3%

| 年份 | 现金流 F | 折现系数 | 现值 PV |
|---|---|---|---|
| 第1年 | 100.0 | 1/(1.10)^1 = 0.909 | 90.9 |
| 第2年 | 110.0 | 1/(1.10)^2 = 0.826 | 90.9 |
| 第3年 | 121.0 | 1/(1.10)^3 = 0.751 | 90.9 |
| 第4年 | 133.1 | 1/(1.10)^4 = 0.683 | 90.9 |
| 第5年 | 146.4 | 1/(1.10)^5 = 0.621 | 90.9 |

- 5年现值合计 = **454.5**
- 终值 TV = F₅ × (1+g∞) ÷ (r − g∞) = 146.4 × 1.03 ÷ 0.07 = **2154.3**，折回今天 = 2154.3 ÷ (1.10)^5 = **1337.7**
- 企业价值 EV = 454.5 + 1337.7 = **1792.2**（终值占 75%——这就是为什么长期假设如此重要）
- **试一试：**把 r 从 10% 改成 11%，EV 会明显下降——这就是「利率上升，成长股下跌」的数学原因。

### 3.2 <abbr title="反过来算：现在的股价要求公司未来增长多快｜Reverse DCF｜比喻：像倒推「要达到这个售价，每年销量必须增长多少」">反向DCF</abbr>（Reverse DCF：反过来算：现在的股价要求公司未来增长多快）
不问「值多少」，而问「现在的价格要求公司长多快」。如果价格要求的增速远高于分析师预期（<abbr title="反向DCF算出的、现价已经「默认」的增长率｜price-implied growth｜比喻：像售价已经把未来涨价预期算进去了">价格隐含增速</abbr>（price-implied growth：反向DCF算出的、现价已经「默认」的增长率） > 共识），说明股票需要持续超预期才能撑住。

### 3.3 <abbr title="分部加总估值：每个业务单独估值再加起来｜Sum-of-the-Parts｜比喻：像集团把各子公司分别估价再合并">SOTP</abbr>（Sum-of-the-Parts：分部加总估值：每个业务单独估值再加起来）
把公司拆成几个业务分别估值再相加（例如特斯拉：汽车 + 储能 + 自动驾驶期权）。本系统的 SOTP 表需要从年报录入分部收入，未录入前留空，避免编造。

### 3.4 <abbr title="用悲观/基准/乐观三套假设分别算结果｜scenario analysis (Bear/Base/Bull)｜比喻：像做预算时的三版方案：保守/目标/挑战">情景分析</abbr>（scenario analysis (Bear/Base/Bull)：用悲观/基准/乐观三套假设分别算结果）
同一家公司用三套假设算三次：悲观/基准/乐观，并给概率（默认 25%/50%/25%）。**比喻：**预算里的保守/目标/挑战三版方案。三个结果之间的距离 = 不确定性有多大。

## 4. 本系统的标签
- **CONFIRMED/DATA（事实）**：官方公布或可核实的数据。
- **MARKET EXP（市场预期）**：共识、期货/预测市场定价。
- **HYPOTHESIS（我们的假设）**：我们的判断，可能错。
- **ASSUMPTION（模型假设）**：Excel 黄色格子，可自己改。
- **UNAVAILABLE**：没有可靠来源，宁可留空也不编。

**✅ 自我测验 Check your understanding**

<details><summary>Q1. DCF 例题里，为什么终值占了大部分价值？</summary>

**答案：**因为第5年以后的所有现金流都被压缩进终值；对长期增长和折现率的假设非常敏感。

</details>
<details><summary>Q2. 价格隐含增速 80%，共识 40%，意味着什么？</summary>

**答案：**市场比分析师乐观得多，股价需要公司持续超预期；一旦增速放缓，股价压力大。

</details>
<details><summary>Q3. SOTP 表为什么是空的？</summary>

**答案：**分部收入需要从年报手工录入；在核实前留空，避免编造数据。

</details>
<details><summary>Q4. 事件书里「预期差」相当于财务工作中的什么？</summary>

**答案：**实际 vs 预算的差异（variance）。

</details>

## 5. 术语表 Glossary
| 术语 | 白话意思 | English | 生活/财务比喻 |
|---|---|---|---|
| DCF | 现金流折现：把未来每年的自由现金流折回今天加总 | Discounted Cash Flow | 像评估一个项目的净现值（NPV） |
| 自由现金流 | 经营现金流减资本开支，真正能分给股东的钱 | Free Cash Flow, FCF | 像现金流量表里「经营现金流 − 购置固定资产」 |
| 折现率 | 把未来的钱换算成今天的钱时用的利率 | discount rate / WACC | 像你评估投资项目时的门槛回报率（hurdle rate） |
| 反向DCF | 反过来算：现在的股价要求公司未来增长多快 | Reverse DCF | 像倒推「要达到这个售价，每年销量必须增长多少」 |
| 价格隐含增速 | 反向DCF算出的、现价已经「默认」的增长率 | price-implied growth | 像售价已经把未来涨价预期算进去了 |
| SOTP | 分部加总估值：每个业务单独估值再加起来 | Sum-of-the-Parts | 像集团把各子公司分别估价再合并 |

# English summary
This guide explains each report type (dashboard, daily, macro, radar, event books, company deep dives, Excel models, My Reports), how to read each chart type, and plain-language valuation methods (DCF with a fully worked illustrative example, Reverse DCF, SOTP, scenarios), plus the claim labels used across the system. Finance-manager analogies: consensus = budget, surprise = variance, DCF = project NPV, scenarios = conservative/target/stretch budgets.
