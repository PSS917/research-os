1. 七步思考法（任何事件都适用）

步骤 你要问的问题 新手常犯的错
① 先问对问题 谁在乎这件事？为什么？它改变的是现金流还是折现率？ 直接猜数字
② 市场定价了什么 共识是多少？价格已经隐含了什么？ 把「坏消息」等同于「会跌」
③ 搭因果链 A → B → C → 股价，每一环用什么数据检验？ 跳过中间环节
④ 找断点 哪一环今天可能不成立？ 以为链条永远成立
⑤ 工具箱质疑 用7个工具逐一拷问（第2节） 只找支持自己的证据
⑥ 对立观点 把反方说到最强，再用证据打分 只驳倒反方的弱版本
⑦ 证伪信号 如果我错了，最先会看到什么？ 事后才找理由

财务经理类比：这就像做一次「预算 vs 实际」分析之前，先确认：预算假设是什么（定价）、差异会通过哪些科目传导到利润（因果链）、哪个科目的口径可能变了（断点）。

2. 质疑工具箱（每次都过一遍）

1. 第一性原理 First principles

拆到最基本：价格 = 未来现金流 ÷ 折现。这件事改变的是现金流还是折现率？

2. 二阶思维 Second-order

然后呢？谁会因此改变行为？二阶、三阶效果是什么？

3. 反向思考 Inversion

什么会让我错？相反结论成立需要哪些条件同时为真？

4. 市场已经定价了什么 Priced-in

共识/价格隐含了什么？只有「实际−预期」推动价格。

5. 谁在对手盘 Counterparty

如果我对，谁错？他们为什么会错？想不出来=可能已被定价。

6. 基础概率 Base rates

这类事情历史上多常发生？先用基础概率，再用本次信息调整。

7. 假设清单与证伪 Assumptions & falsifiers

逐条写出假设，并给每条一个推翻它的可观察信号。

CPI 示范（一句话版）：① CPI 只改变折现率不改变芯片销量；② 偏热→美元↑→USD/JPY 近160→日本干预风险→套息平仓；③ 「CPI引发大跌」需要四个条件同时成立；④ 共识0.2%，0.2%本身不是新闻；⑤ 半导体已跌7.4%，剩下的卖家变少；⑥ 过去36个月53%偏热，而我们只给25%；⑦ 假设A1–A5各有证伪信号。

3. 估值思维：估值不是算一个数，而是问「价格要求什么为真」

3.1 DCF（Discounted Cash Flow：现金流折现：把未来每年的自由现金流折回今天加总）——像算项目NPV（纯举例数字）

F₁=第1年自由现金流（Free Cash Flow, FCF：经营现金流减资本开支，真正能分给股东的钱）=100，g=前5年增长10%，r=折现率（discount rate / WACC：把未来的钱换算成今天的钱时用的利率）10%，g∞=永续增长3%。 5年现值合计 454.5；终值 TV = F₅×(1+g∞)÷(r−g∞) = 2154.3，折现后 1337.7；EV = 1792.2（终值占 75%）。 思考题：r 从10%变11%，EV 变成 1561.1（-13%）。→ 这就是为什么 CPI（影响 r）会动成长股：不是公司变差，而是分母变大。 ### 3.2 反向DCF（Reverse DCF：反过来算：现在的股价要求公司未来增长多快）——反向思考在估值上的应用 不问「值多少」，问「现价要求公司每年长多快？这个要求合理吗？」若价格隐含增速（price-implied growth：反向DCF算出的、现价已经「默认」的增长率）远高于共识（例：OS 模型中 RKLB 115% vs 41%），就要问：谁在为这个乐观买单？什么证据能支持它？ ### 3.3 SOTP（Sum-of-the-Parts：分部加总估值：每个业务单独估值再加起来）——第一性原理拆分 把公司拆成业务，各自估值。问：哪一块业务撑起了大部分价值？那一块最脆弱的假设是什么？ ### 3.4 情景分析（scenario analysis (Bear/Base/Bull)：用悲观/基准/乐观三套假设分别算结果）——不是三个数字，而是三个故事 每个情景都要写：要发生什么、概率依据（基础概率+本次信息）、证伪信号。财务经理类比：保守/目标/挑战三版预算。

4. 对一只股票怎么用（模板）

  1. 价格隐含了什么？（反向DCF）
  2. 现金流的核心驱动是哪1–2个变量？（第一性原理）
  3. 驱动变量的因果链与断点？（例：AI Capex → GPU 订单 → CoWoS 产能 → 收入）
  4. 对手盘是谁？（谁在卖、为什么）
  5. 反方最强论点是什么？证据打分。
  6. 下一个能检验论点的事件是什么？（财报/数据），提前写好证伪信号。

5. 每次事件后的推理复盘清单

  • 因果链哪一环成立、哪一环断了？
  • 哪条假设被证伪？
  • 误差类型：基本面 / 预期定价 / 市场反应 / 时机 / 概率校准
  • 一句话教训：「下次我会先检查 ____」

6. 练习（考推理，不考记忆）

✅ 自我测验 Check your understanding

Q1. 一家公司财报超预期，股价却下跌。用「市场定价了什么」和「对手盘」两个工具各给一个解释。

答案：定价：市场预期的「耳语数」比共识更高，或指引不及预期；对手盘：之前大量押注上涨的资金借利好兑现卖出。

Q2. 利率上升对一家现金流稳定、几乎无负债的公司和一家亏损的高成长公司，影响为什么不同？

答案：后者的价值大多来自遥远未来的现金流（终值占比高），折现率上升对其现值打击更大；前者价值集中在近期。

Q3. 你看好某只股票，请用「反向思考」写出两个让你错的条件。

答案：例：价格隐含增速高于公司历史最好水平；关键客户转向竞争对手/自研。

Q4. 基础概率说某事件发生率 50%，但你只给 20%。你需要什么样的证据才能合理化这个差距？

答案：需要本次有明确、可验证的特殊信息（例如一次性因素回吐、领先指标转向），而且这些信息未被市场共识完全反映。

7. 术语表

术语 白话意思 English 生活/财务比喻
DCF 现金流折现：把未来每年的自由现金流折回今天加总 Discounted Cash Flow 像评估一个项目的净现值（NPV）
自由现金流 经营现金流减资本开支，真正能分给股东的钱 Free Cash Flow, FCF 像现金流量表里「经营现金流 − 购置固定资产」
折现率 把未来的钱换算成今天的钱时用的利率 discount rate / WACC 像你评估投资项目时的门槛回报率（hurdle rate）
反向DCF 反过来算：现在的股价要求公司未来增长多快 Reverse DCF 像倒推「要达到这个售价，每年销量必须增长多少」
价格隐含增速 反向DCF算出的、现价已经「默认」的增长率 price-implied growth 像售价已经把未来涨价预期算进去了
SOTP 分部加总估值：每个业务单独估值再加起来 Sum-of-the-Parts 像集团把各子公司分别估价再合并
情景分析 用悲观/基准/乐观三套假设分别算结果 scenario analysis (Bear/Base/Bull) 像做预算时的三版方案：保守/目标/挑战

English summary

A reusable seven-step reasoning method (right question → what’s priced → causal chain → break points → 7-tool questioning: first principles, second-order, inversion, priced-in, counterparty, base rates, assumptions/falsifiers → steelman & judge → falsifiers), valuation as “what must be true” (DCF worked example: r 10%→11% changes EV -13%), a per-stock template, and a post-event reasoning checklist. Finance-manager analogies throughout.
